# Demonstração do sistema de pedidos (Resenha e Brasa)

Publicada em /demonstracao/sistema-de-pedidos/ (pasta public). Dados inventados, banco só na memória do navegador:
ao recarregar a página, tudo volta ao início. Nada é enviado; os botões de WhatsApp só mostram a mensagem.

Para gerar de novo: copiar estes arquivos para uma pasta `demo/` dentro de uma cópia do repositório
resenhaebrasa-pedidos e rodar `npx vite build -c demo/vite.config.js`. O resultado sai em `dist-demo/`.
